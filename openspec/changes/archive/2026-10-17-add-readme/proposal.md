## Why

The repository has no `README.md`: its GitHub page does not say what the repository is, how to
install it, or where the process is specified. The repository description ("Portable
agent-process and Claude Code plugin marketplace") does not say what the process does either.

## What Changes

- Add a root `README.md` in the
  [standard-readme](https://github.com/RichardLitt/standard-readme/blob/main/spec.md) section order
  that links to the documents owning each detail (design D1, D2).
- Add an MIT `LICENSE`: the owner lets others use the code for free (design D1).
- Replace the GitHub repository description with the README's one-line description (design D3).
